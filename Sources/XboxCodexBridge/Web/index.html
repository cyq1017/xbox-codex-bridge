VOICE SETUP

LT 直接控制听写

系统设置 → 隐私与安全性 → 辅助功能 允许桥接器或启动它的终端。等 Codex 回复结束后，按住 LT 开始听写，松开停止；无需绑定 F13 快捷键。

推理循环、Fast、Review、任务槽位和环境动作仍保留在动作目录，但没有稳定适配器时不会进入默认布局，也不会假报执行成功。
