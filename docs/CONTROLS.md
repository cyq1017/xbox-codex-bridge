# 完整键位与反馈

这里记录 v0.1.0 Preview 的默认映射。网页控制台可以修改映射，但 LT、LB 和 RB 是固定控制。

## 基础层

| 操作 | 功能 |
| --- | --- |
| Share | 启动或聚焦 Codex |
| Xbox Logo | 尝试启动或聚焦；可能被 macOS 或游戏工具占用 |
| LT 按住/松开 | 开始/停止语音输入 |
| LT 双击 | 锁定录音；再按一次停止 |
| RT 单击 | 发送输入框内容 |
| RT 长按 | 插入换行，不发送 |
| B | 中止任务或关闭弹层 |
| X / 十字键下 | 打开或关闭底部面板 |
| Y | 新建任务 |
| MENU / 十字键上 | 打开或关闭侧边栏 |
| A | 打开或关闭侧面板 |
| 十字键左/右 | 上一个/下一个任务 |
| 左摇杆 | 连续移动光标；上/下到当前行首/行尾 |
| 右摇杆 | 连续扩展选区；上/下选到当前行首/行尾 |
| L3 | 删除选区；无选区时删除前一个完整字符 |
| R3 单击/长按 | 聚焦输入框/清空输入框 |

## 任务层：按住 LB

输出文字交互要求先用鼠标或触控板选中文字，让 Codex 原生浮动工具栏出现。

| 操作 | 功能 |
| --- | --- |
| LB + A | 添加到任务 |
| LB + X | 在侧边聊天中提问 |
| LB + Y | 更多详情 |
| LB + 十字键左/右 | 切换任务 |
| LB + 十字键上 | 置顶或取消置顶 |
| LB + RT | 新建任务 |

## 开发层：按住 RB

| 操作 | 功能 |
| --- | --- |
| RB + A | 打开模型与推理强度菜单 |
| RB + RT | 发送并在任务完成后震动提醒 |
| RB + X | 切换 Fast 模式 |
| RB + Y | 切换 Plan 模式 |
| RB + B | 打开终端 |
| RB + 十字键下 | 打开或关闭底部面板 |
| RB + L3 | 打开文件夹 |

进入模型菜单后，用十字键移动，A 进入或确认，B 返回，十字键左/右处理多级菜单。菜单打开期间，这些按键被菜单独占，不会触发全局面板动作。

## 安全层：同时按住 LB + RB

| 操作 | 功能 |
| --- | --- |
| LB + RB + Y | 打开 Codex 原生权限模式菜单 |
| A 长按 | 确认真实审批卡片 |
| B 长按 | 拒绝真实审批卡片 |

权限菜单打开后松开 LB/RB，用十字键上/下选择，A 确认，B 或十字键左取消。选择 Full access 后，Codex 的二次确认仍然保留。

## 窗口与系统层

| 操作 | 功能 |
| --- | --- |
| View 单击 | 显示所有 Codex 窗口；十字键选择，A 进入，B 取消 |
| View + X | 新建不继承当前项目的独立任务 |
| View + Y | 打开 Codex 原生“打开文件夹”流程 |
| View + 十字键左/右 | 跨显示器与 Space 切换 Codex 窗口 |
| View + A | 设置 |
| View + B | 键盘快捷键 |

## 震动反馈

### 任务完成

`RB + RT` 会发送当前输入并开始跟踪：

1. 确认 Codex 出现真实运行状态；
2. 等待运行状态消失；
3. 连续确认处于稳定空闲；
4. 震动两次并让网页 HUD 闪烁。

普通 RT 不启动跟踪，因此短对话不会不断震动。任务完成提醒不依赖 `Stop` Hook。

### 人工审批

将 [`Hooks/codex-haptics-hooks.json`](../Hooks/codex-haptics-hooks.json) 中的 `PermissionRequest` 条目合并到 `~/.codex/hooks.json`，不要覆盖已有 Hook。重启 Codex，并在提示时检查、信任命令。

Hook 只通知 Bridge 检查界面。只有同一 Codex 窗口中同时存在可点击的允许与拒绝控件时，手柄才震动三次；自动审批保持安静。

### 手动测试

网页控制台的震动测试会产生一次长震动。灯光和震动按钮只在 Apple GameController 暴露对应能力时启用。
