# Xbox 手柄控制 Codex｜100 秒小红书拍摄脚本

## 成片目标

- 时长：90–110 秒
- 比例：9:16，1080 × 1920
- 风格：真实操作、快节奏、少解释
- 核心叙事：用一次完整任务证明手柄已经覆盖 Codex 的高频工作流
- 核心标题：**我把 Xbox 手柄变成了 Codex 控制台**

## 主片包含的按键

| 按键 | 画面意义 | 是否必须 |
| --- | --- | --- |
| `Xbox Logo` / `Share` | 一键启动或聚焦 Codex；Share 是 Logo 被系统占用时的备用键 | 二选一，实体测试通过后作为起手 |
| `View + X` | 新建不继承项目的独立任务 | 必须 |
| `R3` | 聚焦输入框 | 必须 |
| `LT` | 按住语音输入，松开停止 | 必须 |
| `RT` | 发送输入内容 | 必须 |
| 左摇杆 | 移动输入框光标 | 必须 |
| 右摇杆 | 扩展文字选区 | 必须 |
| `L3` | 删除选中文字或光标前一个字符 | 必须 |
| 长按 `R3` | 清空输入框 | 必须 |
| 轻按 `View` | 打开 Codex 窗口选择器 | 必须 |
| 十字键 + `A/B` | 选择窗口并进入 / 取消 | 必须 |
| `View + Y` | 调用 Codex 原生“打开文件夹”项目入口 | 必须，实体测试通过后录 |
| `X` / `MENU` | 开关底部面板 / 侧边栏 | 二选一即可 |
| `RB + A` | 打开模型和推理设置 | 可选，实体测试通过才加入 |
| `RB + D-pad 左右` / `RB + RT` | 降低/提高/循环推理强度 | 可选，实体测试通过才加入 |
| `RB + X` / `RB + Y` | Fast / Plan 模式 | 可选，实体测试通过才加入 |
| `LB + RB + A/B` | 长按批准 / 拒绝 | 可选，只有真实批准画面才加入 |

优先拍 `Xbox Logo` 一键聚焦 Codex；如果 macOS 仍把 Logo 留给游戏或系统覆盖层，就改拍 `Share`。不要把未经实体确认的 Logo 画面写进标题或字幕。`View + X` 只讲“新建独立任务”，不要说它负责唤醒 Codex。

## 100 秒分镜

| 时间 | 画面与操作 | 口播 | 屏幕大字 |
| --- | --- | --- | --- |
| 0–4s | 手机拍手柄和显示器。画面先停留在其他应用，按 `Xbox Logo`；若系统拦截则按 `Share`，Codex 被带到前台。随后按住 `View`、轻按 `X` 新建独立任务。 | “我把 Xbox 手柄，做成了 Codex 控制台。” | 一键唤醒 · 独立任务 |
| 4–10s | 切到本地映射网页，快速带过“手柄已连接、辅助功能、震动”。 | “不是概念图，所有按键都在本机实时映射。” | 已连接 · 本地映射 |
| 10–15s | 回到 Codex，按一下 `R3`，输入框出现光标。 | “R3 先把光标定位到输入框。” | `R3` 聚焦输入框 |
| 15–28s | 按住 `LT` 说：“请用三步说明这个 Xbox Codex 项目适合解决什么问题。”松开后显示转写，再按 `RT`。 | “按住 LT 直接说话，松开结束；RT 直接发送。” | `LT` 语音 · `RT` 发送 |
| 28–37s | 保留 Codex 开始回答的真实画面。可局部放大输入内容和任务执行状态。 | “从语音到发送，不需要再碰键盘。” | 全程手柄输入 |
| 37–50s | 使用单独录制的输入框镜头。预先放入两行文字：第一行保留，第二行写“这一行请删除”。左摇杆移动光标，右摇杆选中第二行，按 `L3` 删除。 | “两个摇杆还能移动光标、扩展选区，L3 删除局部文字。” | 光标 · 选区 · 删除 |
| 50–55s | 输入框再次放入一段测试文字，长按 `R3` 约 0.5 秒，文字全部清空。 | “长按 R3，整段清空。” | 长按 `R3` 清空 |
| 55–67s | 轻按 `View`，出现窗口清单；用十字键切换选中项，按 `A` 进入另一个 Codex 窗口。再录一个按 `B` 取消的短镜头备用。 | “轻按 View，可以看到当前所有 Codex 窗口，再用十字键和 A 直接切过去。” | Codex 多窗口选择器 |
| 67–76s | `View + Y` 弹出 Codex 原生文件夹选择器。停留 2 秒展示结果；如果不想真的创建项目，松开 View 后按 `B` 关闭。 | “View 加 Y，则从文件夹开始一个项目任务。” | `View + Y` 文件夹项目 |
| 76–83s | 回到普通任务，按 `X` 展开或收起底部面板，再按 `MENU` 展开或收起侧边栏。只保留画面变化最清楚的一次。 | “终端和侧边栏，也能直接控制。” | 面板控制 |
| 83–93s | 展示网页五层映射；手机近拍手柄，点击网页手动震动测试。只有手柄确实震动才保留。 | “按键可以在网页里重映射；震动通道已经接通，我把它留给人工批准提醒。” | 5 层映射 · 震动通道 |
| 93–103s | 手柄、Codex 和映射网页同框。可以快速闪过 Swift、GameController、Accessibility 三个词。 | “它还没有百分之百替代 Codex Micro，但高频操作已经够我真实使用了。” | 高频工作流已覆盖 |
| 103–108s | 定格手柄，结尾提问。 | “你觉得下一个最该加什么功能？” | 下一步加什么？ |

## 可选的 5 秒推理镜头

只有模型控制实体测试确认后，才把它插在语音输入前：

- 画面：按住 `RB`，轻按 `A` 打开模型设置；可接 `RB + D-pad 右` 或 `RB + RT`，拍到推理强度真实变化。
- 口播：“发送前，我还能直接选模型、调整推理强度。”
- 屏幕大字：`RB + A` 模型 · `RB + RT` 推理强度

如果状态变化不够清楚，直接删除这段，不影响主片叙事。

## 录制方式

不要一次录完整 100 秒。分别录下面 7 个原片，每个动作前后保留 0.5–1 秒静止画面：

1. `01_hook_launch.mp4`：Xbox Logo 或 Share 聚焦 Codex，再 View+X 新建任务，5–8 秒。
2. `02_voice_send.mp4`：R3、LT 语音、RT 发送，15–20 秒。
3. `03_text_edit.mp4`：光标、选区、删除、清空，15–20 秒。
4. `04_window_picker.mp4`：View、十字键、A/B，10–15 秒。
5. `05_project_folder.mp4`：View+Y 文件夹入口，8–12 秒。
6. `06_panels_dashboard.mp4`：面板、侧边栏、映射网页，10–15 秒。
7. `07_controller_haptic.mp4`：手机近拍手柄和震动测试，5–8 秒。

最后单独录一条完整口播。操作和口播分开，可以在 ChatCut 中轻松删除停顿、口误和失败操作。

## ChatCut 剪辑顺序

1. 新建 9:16、1080 × 1920、30fps 时间线。
2. 先放完整口播，删除重复句、口头禅和超过约 0.25 秒的无意义停顿。
3. 按上面的时间顺序铺屏幕录制，用真实操作画面覆盖对应口播。
4. 重要按键发生前保留约 0.3 秒，动作结果至少停留 1 秒，不要剪得观众看不清。
5. 给 Codex 输入框、窗口选择器和按键状态做 110%–125% 的局部放大。
6. 生成中文字幕：每行不超过 12 个汉字，最多两行；`View+X`、`LT`、`RT`、`R3` 使用青绿色强调。
7. 最后再加低音量电子音乐、简单转场和封面；先在编辑器审片，不要直接导出。

## 录制前的快速验收

- `Xbox Logo`：Codex 被聚焦；若系统拦截，`Share` 可以聚焦 Codex。
- `View + X`：新任务不出现在之前项目标题下。
- `View + Y`：出现 Codex 原生文件夹选择器。
- `LT`：真实出现听写文本；`RT`：真实发送。
- 左摇杆、右摇杆、`L3`、长按 `R3`：动作结果清楚可见。
- 轻按 `View`：窗口选择器真实出现，十字键和 `A` 可以切换。
- 普通发送、新建任务和回复完成都不应震动。
- 画面中没有私人项目名、路径、账号、通知、终端历史或密钥。
