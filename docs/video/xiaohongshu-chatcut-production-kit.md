# Xbox Codex Bridge 小红书视频制作包

完整的 90–110 秒逐镜头拍摄版本见 [`xiaohongshu-100s-shooting-script.md`](./xiaohongshu-100s-shooting-script.md)。

## 先发布版（80% 即可）

先做一条 45–55 秒的真实操作版，不等待所有 Micro 边角功能。主片只保留下面 6 组已经接入、且适合观众理解的高频动作：

1. LT 语音输入，RT 发送。
2. View+X 新建无项目任务；View+Y 从 Codex 原生“打开文件夹”入口开始项目任务。
3. 轻按 View 打开 Codex 窗口清单，十字键选择，A 进入，B 取消。
4. 左摇杆移动光标，右摇杆扩展选区，L3 删除，长按 R3 清空输入框。
5. 本地网页显示手柄连接、当前层和可编辑映射。
6. 只在真实批准请求或手动测试时展示震动。

推理强度、Fast、输出选择交互、Git/PR、状态灯都作为第二版可选素材；没有完成实体测试就不要录进主片。这里的“80%”指可发布演示故事已经完整，不宣称覆盖 Codex Micro 全部硬件能力。

最省事的录制方式：先分别录 5 段 6–10 秒的屏幕素材，再单独录一条口播。不要边操作边口播；分开录更容易在 ChatCut 中删错字、停顿和失败操作。

## 视频定位

- 形式：真人手柄操作 + Codex 屏幕录制 + 少量网页映射面板
- 比例：9:16，1080 × 1920
- 时长：55–65 秒
- 核心标题：**我把 Xbox 手柄变成了 Codex 控制台**
- 备选标题：
  - 不买 Codex Micro，我用 Xbox 手柄复刻了一套
  - 用手柄操控 Codex，居然比键鼠更顺手
  - 这不是游戏：Xbox 手柄正在控制 Codex
- 封面大字：**Xbox × Codex**
- 封面小字：**语音 / 多窗口 / 光标编辑 / 新建任务**

## 公开前的素材安全

ChatCut 是云端网页编辑器。只上传专门录制的演示素材：

- 新建一个无隐私内容的 Codex 演示项目和演示任务。
- 关闭或裁掉真实项目名、用户目录、账号、通知、终端历史和侧边栏中的私人任务。
- 终端镜头只展示桥接器启动和测试输出，不展示环境变量或其他命令历史。
- 不使用包含 API Key、Cookie、邮箱、私有仓库、客户数据的画面。
- 第一次导出后逐帧检查字幕、窗口切换镜头和终端镜头。

## 建议录制的素材

按以下名称保存，方便在 ChatCut 中引用：

1. `01_hook_controller.mp4`：手机拍手柄和显示器，按下 Xbox 键或 View，3–4 秒。
2. `02_voice_send.mp4`：屏幕录制，LT 语音输入，RT 发送，8–10 秒。
3. `03_window_picker.mp4`：轻按 View，显示窗口清单，十字选择，A 进入另一个显示器上的窗口，8–10 秒。
4. `04_new_tasks.mp4`：View+X 新建不属于任何项目的 standalone task；View+Y 通过 Codex 原生“打开文件夹”入口选择文件夹并新建项目任务，8–10 秒。
5. `05_composer_edit.mp4`：摇杆移动光标、扩展选区，L3 删除局部文字，7–9 秒。
6. `06_output_actions.mp4`：选中 Codex 输出，展示“添加到任务 / 侧边聊天提问 / 更多详情”，6–8 秒。
7. `07_dashboard_haptic.mp4`：本地映射网页、层切换、按键状态和震动测试，6–8 秒。
8. `08_talking_head.mp4`：完整口播一遍，保留自然停顿，ChatCut 负责删停顿和补 B-roll。

录屏时让每个动作前后各留约 0.5 秒静止画面，方便剪辑。

## 60 秒口播稿

> 我没有买 Codex Micro，我直接拿 Xbox 手柄做了一套。
>
> 按住 LT 就能对 Codex 说话，松开停止；RT 直接发送。
>
> 轻按 View，会列出现在打开的所有 Codex 窗口。十字键选择，A 进入，哪怕窗口在另一块屏幕或另一个桌面空间，也能切回来。
>
> View 加 X，会直接开一个不属于任何项目的新任务；View 加 Y，则从文件夹开始一个新项目任务。
>
> 两个摇杆还能移动光标、扩展选区，L3 删除局部文字。选中 Codex 的回答后，还能用手柄添加到任务、在侧边聊天里追问，或者打开更多详情。
>
> 所有动作都能在这个本地网页里重新映射；需要人工批准时，手柄会用三段震动提醒。
>
> 它还不是百分之百的 Codex Micro：任务状态灯、Fast 和推理强度控制还需要继续接入。但现在，高频工作流已经真的能用起来了。
>
> 整套工具是 Swift、GameController 和 macOS Accessibility 做的。你还想让我给手柄加什么 Codex 功能？

## 发布前验收

- 第 2 秒前出现真实结果，而不是 Logo 或铺垫。
- View+X、View+Y 的表述与最终实体测试一致。
- 普通回复结束不震动；真实批准请求才自动震动。
- 所有演示动作都来自真实录屏。
- 没有私人任务、路径、邮箱、通知或终端历史。
- 字幕没有挡住 Codex 输入框和窗口选择器。
- 人声在手机外放时仍清楚，音乐不抢。
- 9:16 预览没有裁掉手柄、按键提示或 Codex 关键区域。
