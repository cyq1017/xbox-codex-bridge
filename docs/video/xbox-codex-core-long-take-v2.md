# Xbox 手柄控制 Codex｜核心长镜头 V2

## 这版可以拍什么

主镜头目标时长为 80–110 秒，一条真实操作链覆盖：

`Share 唤醒 → View+X 独立任务 → 模型 → 推理强度 → 权限 → LT 语音 → RT 发送 → B 取消 → 工作面板 → 人工批准三连震`

窗口选择、项目文件夹、文字选区和网页映射单独补拍，最后在 ChatCut 中插入主镜头。

> 真实性边界：当前已启用的是“出现人工批准卡时三连震”。普通回复或任务完成不会自动震动，因此画面和字幕都不要写“任务完成提醒”。

## 录制前准备（不进正片）

1. 不退出 Codex，只把它最小化或切到 Finder；起手使用 **Share**，不要使用可能被 macOS 抢走的 Xbox Logo。
2. 新建或打开一个没有私人项目名、路径、账号和终端历史的演示窗口。
3. 关闭通知；录屏只框住 Codex 主区域。
4. 打开 `http://127.0.0.1:8765/`，确认手柄、辅助功能和震动均为已连接。
5. 手机拍手柄近景时把手柄放在硬桌面上，三连震更容易被画面和声音捕捉。
6. 正式拍摄时不做实时口播；只保留 LT 的真实语音指令，其余说明后期加字幕或旁白。
7. 每个动作前后停 0.5–1 秒，方便 ChatCut 剪切。

## 主长镜头：逐秒操作

### 0–6 秒｜一键唤醒

- 画面先停在 Finder 或浏览器。
- 单按 **Share**，等待 Codex 回到前台。
- 字幕：`Share → 一键唤醒 Codex`

### 6–14 秒｜新建独立任务

- 按住 **View**，轻按 **X**，随后松开。
- 等待新的独立任务输入框出现。
- 字幕：`View + X → 新建独立任务`

### 14–30 秒｜选择模型

1. 按住 **RB**，轻按 **A**。
2. **先松 A，再立即松 RB**，等待 0.4–0.7 秒。
3. 裸按十字上／下，在一级菜单选中“模型”。
4. 按 **A** 或十字右进入二级菜单。
5. 等待 0.3–0.5 秒，用裸十字上／下选择一个模型。
6. 按 **A** 确认。

字幕：`RB + A → 选择模型`

> 菜单打开后不要继续按住 RB，否则 A 可能被识别为重新打开选择器。

### 30–45 秒｜选择推理强度

重新执行一次：

1. **RB + A**，然后完全松开 RB。
2. 十字上／下选中“推理强度”。
3. **A** 或十字右进入二级菜单。
4. 十字上／下选择强度，按 **A** 确认。

字幕：`模型和推理强度都能手柄选择`

> 当前没有 `RB + 十字左右` 或 `RB + RT` 直接调强度的映射，不要在视频中这样讲。

### 45–57 秒｜选择权限模式

1. 同时按住 **LB + RB**，轻按 **Y**。
2. 先松 Y，再松开两枚肩键，等待约 0.4 秒。
3. 必须先裸按一次十字上／下，让高亮移动到“请求批准”。
4. 按 **A** 确认。

字幕：`LB + RB + Y → 权限模式`

> 主镜头选“请求批准”，不要选“完全访问”，避免进入额外二次确认。

### 57–72 秒｜语音发送并演示取消

1. 按 **R3** 聚焦输入框。
2. 按住 **LT** 说：

   > 请连续输出一百行测试文字，每行写明当前行号。

3. 松开 LT，等转写出现后轻按 **RT** 发送。
4. 等 Codex 开始输出，再按一次 **B** 停止任务。

字幕依次出现：

- `LT → 按住说话`
- `RT → 发送`
- `B → 停止当前任务`

### 72–98 秒｜触发真实批准提醒

1. 再按住 **LT**，说：

   > 请只使用终端运行 curl head example.com。需要网络权限时必须等待我人工批准，不要使用网页工具，也不要创建、修改或删除文件。

2. 松开 LT，轻按 **RT** 发送。
3. 等待人工批准卡出现；不要立刻点击，让三连震有时间触发。
4. 可按 **X** 展开底部面板，停留 1–2 秒后再按 X 收起。
5. 为避免真的执行网络请求，按住 **LB + RB + B** 约 0.35 秒拒绝。

字幕：

- `需要人工批准 → 手柄三连震`
- `LB + RB + B → 拒绝`
- `X → 工作面板`

> 如果本次请求被自动审批、没有出现真实批准卡，就不要伪造震动画面。保留主镜头到 RT 发送处，批准与震动改用补拍素材。

### 98–108 秒｜结尾定格

- Codex、手柄和桥接网页同框。
- 字幕：`Xbox × Codex｜高频工作流已覆盖`
- 结尾问题：`你还想把哪个 Codex 功能放进手柄？`

## ChatCut 剪辑原则

- 主长镜头作为叙事骨架；失误处用对应补拍素材覆盖，不需要整条重录。
- 保留 LT 的真实语音，其他说明后期加旁白或字幕。
- 按键出现前至少留 0.3 秒，结果至少停留 1 秒。
- 模型、权限菜单和批准卡可放大到 115%–125%。
- 字幕不得写“任务完成自动震动”；只写“人工批准提醒”或“震动通道测试”。
- 第一次剪辑保持可编辑时间线，不急着导出。

## 正式录制前最后一次排练

只走下面这条，不录屏：

`Share → View+X → RB+A 选模型 → RB+A 选强度 → LB+RB+Y 选请求批准 → LT → RT → B → LT curl 指令 → RT → 等批准卡与三连震`

全部通过后再开始正式录制；其中任何菜单失效，就用对应补拍素材，不让一个动作拖垮整条主镜头。
