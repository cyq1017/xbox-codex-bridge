# Xbox Codex Bridge v0.1.0 Preview

The first public preview turns an Xbox controller into a local Codex control surface on macOS.

## Highlights

- Hold LT to dictate into the current Codex composer.
- Tap RT to send; hold RT to insert a newline; press B to stop.
- Open native model, reasoning, permission, task, and window controls from the controller.
- Use the sticks to move the caret and extend text selection continuously.
- Use `RB + RT` to send a tracked task and receive two haptic pulses when it completes.
- Receive three haptic pulses when a real human approval card is detected through the optional hook.
- Inspect mappings and device capabilities from the loopback-only dashboard.

## Install

```bash
git clone https://github.com/cyq1017/xbox-codex-bridge.git
cd xbox-codex-bridge
./run.command
```

Enable **Xbox Codex Bridge** under **System Settings → Privacy & Security → Accessibility**, then run `./run.command` once more.

## Verification

Automated checks:

```bash
./Scripts/release-check.sh
```

The core flow was exercised during the recorded release demo. The [v0.1.0 controller smoke test](v0.1.0-smoke-test.md) remains an optional compatibility check for other controller models, macOS versions, and connection types.

## Preview limitations

- This release is source-first and is not notarized by Apple.
- Codex UI labels may change between desktop-app versions.
- Xbox Logo, Share, haptics, and light capabilities vary by controller model and connection type.
- The exact Codex Micro hardware event is private; dictation is reproduced through macOS Accessibility.

Xbox Codex Bridge is an independent community project and is not affiliated with OpenAI or Microsoft.
