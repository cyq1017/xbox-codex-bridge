# Changelog

All notable user-visible changes will be documented in this file.

## 0.1.0 - 2026-08-01

- Added Xbox controller layers for input, task, developer, safety, and window actions.
- Added LT push-to-talk dictation through macOS Accessibility.
- Added opt-in completion haptics for tasks sent with `RB + RT`.
- Added approval-request haptics through an optional Codex hook.
- Added the local mapping and diagnostics dashboard on `127.0.0.1:8765`.
- Added background LaunchAgent installation and safe uninstall support.
